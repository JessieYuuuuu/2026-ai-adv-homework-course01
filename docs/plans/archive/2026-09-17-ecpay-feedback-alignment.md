## User Story

作為本機開發者，我希望 AIO 表單的 ReturnURL 指向專案內存在的路由，並使付款方式、測試與文件一致，同時清楚標示本機通知路由不處理付款結果。

## Spec

- 新增 `POST /api/ecpay/notify`，不要求 JWT，固定回覆 HTTP 200、純文字 `1|OK`；不驗簽、不更新訂單。
- ReturnURL 使用 `BASE_URL` 或本機預設網址加上該路徑；ClientBackURL 保持返回訂單詳情。
- 維持表單 `ChoosePayment=ALL`，修正原先預期 `Credit` 的測試與現行文件。
- 綠界無法連入 localhost；付款狀態仍只由後端主動查詢、驗簽後更新。離線付款方式未完成端到端驗收。
- 將 `docs/` 中混用的簡體字改成繁體，保留識別字及歷史計畫原文，並為歷史計畫補註後續變更。
