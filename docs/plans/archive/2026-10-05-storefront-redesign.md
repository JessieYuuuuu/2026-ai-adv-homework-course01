# 消費者前台購物流程設計與切版

## User Story

身為花漾生活的訪客與會員，我希望消費者前台具有一致、清楚且能辨識品牌的介面，讓我能在桌面與行動裝置順利選花、結帳、確認訂單及查看付款結果。

## Spec

- 將原本常見的粉色圓角卡片風格改為「黑金高級花藝會所」。
- 建立曜石黑、炭黑、香檳金、古銅金與象牙白的色彩系統，統一字體、間距、邊框與互動焦點。
- 重做首頁主視覺、精選商品、品牌故事與完整商品目錄。
- 更新前台導覽、頁尾、表單、表格、商品詳情、購物車、結帳、訂單、登入與空狀態的共用樣式。
- 管理後台不在本次設計與切版範圍。
- 不變更 API、Vue 資料綁定、認證、購物車、訂單或付款契約。
