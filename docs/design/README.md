# 花漾生活前台黑金版設計稿

本資料夾保存以 `frontend-design` skill 為設計基底，透過 Pencil MCP 建立的消費者前台原生畫布設計稿截圖。設計先在 Pencil 畫布完成，再作為 EJS 與 Tailwind CSS 切版的比對基準；管理後台不在本次作業範圍。

## 設計系統

- 主色：曜石黑 `#080806`、炭黑 `#191814`
- 強調色：香檳金 `#C8A96A`、古銅金 `#8C6E35`
- 文字色：象牙白 `#F2EEE5`、灰褐 `#AAA398`
- 標題：Noto Serif TC
- 內文：Noto Sans TC
- 英文與價格：Cormorant Garamond

Pencil 畫布包含可編輯的桌面與手機 Frame；PNG 為作業提交與版本檢查用的固定快照。
